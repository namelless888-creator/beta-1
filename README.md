# Бета 1

Приложение для оформления рабочего стола Windows по согласованному концепту с Porsche. Обои не меняет. Первая реализация интерфейса, а не завершённая копия макета: визуальное совпадение и интеграцию с оболочкой ещё требуется проверить на Windows.

## Запуск

Windows 10 версии 2004 или новее / Windows 11, x64. Откройте **Actions → Build Windows → последний успешный запуск → Artifacts → Beta1-Windows-x64**, распакуйте архив и запустите `Beta1.exe`. Устанавливать .NET отдельно не нужно. Сборка не подписана цифровой подписью.

При самостоятельной сборке установите .NET 8 SDK:

```powershell
dotnet publish Beta1.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
.\publish\Beta1.exe
```

## Что реализовано

- Верхняя панель, часы, музыкальный виджет, список приложений, папки, док и панель состояния.
- Текущие время и дата; медиаданные, обложка и прогресс из системной медиасессии Windows; управление медиаклавишами.
- Сканирование ярлыков меню «Пуск» и рабочего стола; поиск, фильтр игр и рабочих приложений.
- Правый клик по приложению — закрепить или убрать из дока. Док показывает до семи закреплений.
- Запуск реальных приложений, переход в выбранные папки, корзину и системные настройки.
- Перемещение любой панели: **Alt + перетаскивание**. **Esc** скрывает панель.
- Значок в системном трее: показать/скрыть панели, настройки, выход.
- Настройка плотности фона, папок, автозапуска, сброс расположения.
- Опциональное скрытие штатной панели задач и значков рабочего стола. При нормальном выходе приложение возвращает скрытые элементы.
- Настройки сохраняются в `%LOCALAPPDATA%\Beta1\settings.json`.

## Что ещё нужно проверить и доработать

Это ранняя версия. Сборка в CI не подтверждает работу графического интерфейса. Нужна проверка на реальном Windows с масштабированием 100%, 125%, 150%, переключением дисплеев, Win+D и полноэкранными играми.

Полупрозрачные панели пока используют тонированную заливку без настоящего Acrylic-размытия. Режимы «Работа» / «Личное» фильтруют список приложений, а не переключают виртуальные рабочие столы Windows. Игры определяются по имени ярлыка. UWP-приложения без ярлыков пока не перечисляются. Системный трей Windows не переносится в собственный док. Имя, исполнитель и обложка появляются только у проигрывателей, публикующих системную медиасессию.

Первичное расположение рассчитано на основной монитор; несколько мониторов и очень маленькие экраны требуют отдельной настройки. После аварийного завершения при скрытой панели задач перезапустите Бета 1 и завершите его штатно либо перезапустите «Проводник» через диспетчер задач. Приложение не меняет обои, системные файлы или настройки оформления в реестре; автозапуск включается только вручную.

## Проверка перед выпуском

1. Запустить на Windows, сравнить расположение и типографику с макетом.
2. Найти и запустить приложение, закрепить в доке, перезапустить Бета 1 и проверить сохранение.
3. Выбрать папки, открыть их; переместить панели и проверить восстановление.
4. Включить музыку в поддерживаемом проигрывателе, проверить обложку, паузу и следующий трек.
5. Включить скрытие оболочки, затем завершить приложение через трей; проверить восстановление.
6. Проверить автозапуск, изменение масштаба экрана и поведение панелей поверх рабочего стола и под обычными окнами.
