# Бета 1 · 0.3.0

Оформление рабочего стола для Windows 10 2004+ / Windows 11 x64. Обои остаются пользовательскими.

## Установка обновления

Завершите предыдущую версию через её меню **Выход**, скачайте `Beta1.exe` из [Releases](https://github.com/namelless888-creator/beta-1/releases) и запустите. .NET устанавливать не требуется. Если старая версия ещё работает, повторный запуск открывает её настройки — поэтому сначала нужно закрыть старый процесс.

## Исправления 0.3.0

- Иконки без стрелок: изображение загружается непосредственно из системного списка иконок с отключёнными наложениями. Запуск сохраняет исходный ярлык, его аргументы и рабочую папку.
- В панели приложений только элементы пользовательского и общего рабочего стола. Меню «Пуск», установленные программы и содержимое вложенных каталогов больше не сканируются. Обычные файлы тоже доступны; скрытые и системные файлы не перечисляются.
- Панель папок — сетка настоящих каталогов рабочего стола, с системными значками и названиями. Предустановленные «Проекты / Документы / Загрузки» удалены.
- Док читает закрепления панели задач Windows через перечислитель Shell, сохраняя порядок. Собственные закрепления Бета 1 и заранее выбранные программы удалены. «Пуск» и поиск остаются отдельными системными кнопками.
- Скрывается только слой значков рабочего стола Windows. Файлы, ярлыки, их атрибуты и расположение на диске не изменяются. Перенос в `desktop-links` полностью убран.
- При обновлении восстанавливаются ярлыки, которые перемещала версия 0.2.0. Код перемещения в новой версии используется только для обратной миграции. Если исходный путь занят, новый файл не перезаписывается.
- Плотные тёмные панели, контрастные подписи, скруглённый поиск с подсказкой, компактная прокрутка и тёмные контекстные меню. Минимальная плотность фона — 90%, чтобы обои не мешали чтению. Старые настройки прозрачности и положения обновляются один раз.
- Изменения на рабочем столе автоматически обновляют сетки. Закрепления Windows перечитываются каждые 15 секунд и по кнопке обновления.

## Настройки и управление

Значок **Бета 1** в собственном трее справа внизу открывает панель управления. Она также доступна из верхней панели, меню «Пуск» → **Бета 1 — Настройки** и при повторном запуске EXE.

Настраиваются масштаб интерфейса, размер иконок в сетках и доке, подписи, плотность фона, скрытие значков рабочего стола, скрытие панели задач Windows, автозапуск и положение панелей.

- **Alt + перетаскивание** перемещает панель.
- **Правый клик** на элементе открывает контекстное меню с обычными действиями.
- **Esc** скрывает выбранную панель. Вернуть панели можно из меню значка Бета 1.
- Чтобы изменить закрепления, временно включите штатную панель задач Windows в настройках Бета 1 и закрепите/открепите приложения в ней.
- Управление музыкой работает через системную медиасессию Windows.

При выходе возвращается видимость скрытых элементов Windows. Отдельный процесс восстановления следит за аварийным завершением. После отключения питания восстановление выполняется при следующем запуске. Настройки и журнал восстановления хранятся в `%LOCALAPPDATA%\Beta1`.

## Проверки

```powershell
dotnet publish Beta1.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
.\publish\Beta1.exe --integration-test
.\publish\Beta1.exe --smoke-test
```

Windows CI проверяет:

- каталог содержит только непосредственные элементы тестового рабочего стола, включая папки;
- пиксели иконки EXE и ведущего к нему ярлыка совпадают, без стрелки;
- скрытие и восстановление тестового слоя `SysListView32` не меняет файлы;
- миграция старого хранилища не перезаписывает новый ярлык;
- семь панелей, масштаб и размеры, границы экрана, док и трей;
- открытие настроек и тёмного контекстного меню.

CI сохраняет снимки **реально отрисованных WPF-панелей** на нейтральном фоне, настроек и меню. Тестовый снимок использует примеры локальных приложений Windows, а не содержимое пользовательского рабочего стола. Он помогает проверить компоновку, но не заменяет проверку поведения оболочки на пользовательском ПК.

## Ограничения

Shell-перечислитель закреплений — недокументированный интерфейс Windows. Если версия системы не предоставляет его, используются доступные `.lnk` из штатной папки закреплений, а в настройках появляется предупреждение о неполном списке и порядке. Приложения не подставляются из произвольного списка. Перечислитель используется только для чтения.

Собственный трей содержит значок Бета 1 и системные кнопки; сторонние значки уведомлений Explorer не перенесены. Скрытие значков применяется ко всему слою рабочего стола, включая системные значки. Панели размещаются на основном мониторе; они используют тонированную заливку без Acrylic-размытия. Поведение с Win+D, полноэкранными играми, сторонней оболочкой и нестандартным DPI требует проверки на конкретном компьютере.

Иконки читаются через `SHGFI_SYSICONINDEX` и `ImageList_GetIcon`, без `SHGFI_ICON`, который может накладывать стрелку даже без соответствующего флага: [пояснение Microsoft](https://devblogs.microsoft.com/oldnewthing/20110127-00/?p=11653).
