# Бета 1 · 0.4.0

Оформление рабочего стола для Windows 10 2004+ / Windows 11 x64. Обои остаются пользовательскими.

Скачайте `Beta1.exe` из [Releases](https://github.com/namelless888-creator/beta-1/releases). Перед обновлением завершите старую версию через меню **Выход** и замените EXE. Установка .NET не требуется. Версия указана в панели управления.

## Новое в 0.4.0

- Док показывает закреплённые программы **и открытые окна**. Первое сканирование выполняется при запуске, поэтому ранее открытые окна тоже попадают в док. Закрытые окна исчезают, свёрнутые остаются.
- Для обычных EXE открытые окна объединяются с соответствующим закреплением. Под значком есть индикатор работы и активного окна. Нажатие переключает / восстанавливает окно; повторное нажатие сворачивает активное. Для нескольких окон открывается список названий.
- Нижний док появляется с анимацией при наведении к нижнему краю и поднимается поверх обычных окон. При уходе курсора скрывается с задержкой; на рабочем столе остаётся видимым. Поведение можно отключить в настройках.
- Используется **живая область уведомлений Explorer**, включая существующие и новые значки, меню программ и стрелку скрытых значков. Бета 1 не создаёт копий сторонних значков и не угадывает их команды. Внешний вид этой части остаётся штатным для Windows.
- В обычном режиме скрыта часть стандартной панели задач с кнопками приложений, а её область уведомлений остаётся доступной рядом с доком Бета 1. Исходная область окна, видимость и положение в порядке окон восстанавливаются при выходе и через процесс восстановления после аварии.
- «Пуск» вызывает системное меню через Ctrl+Esc, лупа — поиск Windows через Win+S. Ввод отправляется после завершения клика.
- Кнопка звука Бета 1 открывает ползунок реальной громкости устройства вывода и выключение звука. Он синхронизируется с Windows. При отсутствии аудиоустройства показывается сообщение и ссылка на устройства.
- Кнопка сети Бета 1 открывает штатную панель доступных подключений. В живом трее кнопки звука и сети сохраняют штатное поведение Windows.

## Рабочий стол и настройки

Приложения и папки берутся только с пользовательского и общего рабочего стола, без сканирования меню «Пуск» и вложенных каталогов. Папки показываются сеткой настоящих системных значков. Иконки извлекаются без наложения стрелок. Скрывается слой значков Windows; файлы и их атрибуты не меняются. При обновлении восстанавливаются ярлыки, которые могла переносить версия 0.2.0.

Значок **Бета 1** в трее, верхняя панель и пункт **Бета 1 — Настройки** в меню «Пуск» открывают панель управления. Доступны масштаб, размеры иконок, подписи, плотность фона, скрытие значков рабочего стола, режим панели задач, автозапуск и сброс положения.

- **Alt + перетаскивание** перемещает панели рабочего стола.
- **Esc** скрывает выбранную панель; вернуть можно через меню Бета 1.
- Закрепления дока берутся из Windows; изменяйте их в штатной панели задач, временно вернув её в настройках.
- Корзина и «Этот компьютер» доступны из меню Бета 1.
- Музыкальный виджет использует системную медиасессию Windows.

## Как устроен живой трей

Explorer продолжает владеть значками и обрабатывать их действия. Бета 1 определяет область уведомлений через `TrayNotifyWnd` либо UI Automation и ограничивает видимую область основной панели задач с помощью оконного региона. Перерегистрация значков, внедрение кода, чтение памяти Explorer и переподчинение его дочерних окон не используются.

Исходный регион сохраняется в журнал **до** изменения. При восстановлении проверяется владелец окна. Если Explorer перезапустится, область определяется заново. После отключения питания восстановление выполняется при следующем запуске Бета 1. Настройки и журнал находятся в `%LOCALAPPDATA%\Beta1`.

## Проверки и сборка

```powershell
dotnet publish Beta1.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
.\publish\Beta1.exe --integration-test
.\publish\Beta1.exe --smoke-test
```

Windows CI проверяет иконки без стрелок и без одинаковых заглушек, чтение только рабочего стола, сохранность файлов при скрытии значков, восстановление слоя значков и миграцию старого хранилища. Дополнительно проверяются обнаружение существующего и свёрнутого окна, сопоставление закреплённого EXE, удаление закрытого окна и восстановление региона после ограничения.

Проверка интерфейса открывает семь панелей, настройки и окно громкости, проверяет границы и масштаб, режим Topmost при раскрытии дока, сохраняет снимки WPF-интерфейса. В отчёт пишутся доступность области трея и процессы, получившие фокус после команд «Пуск» / поиска. Отсутствие аудиоустройства или Wi-Fi в CI не подтверждает управление реальными устройствами пользователя.

## Границы поддержки

Живая область уведомлений сохраняет оформление Windows. В нестандартных сборках Explorer определение её границ может не поддерживаться; в настройках появляется пояснение, а штатная панель задач остаётся доступной. Размещение дока рассчитано на основной монитор. Поверх исключительного полноэкранного режима игры или защищённого рабочего стола Windows обычное окно может не отображаться.

Полный список закреплений читается через недокументированный Shell-интерфейс. При его недоступности используются штатные `.lnk` закреплений, и настройки сообщают о неполном списке. Для некоторых Store-приложений закреплённый значок и открытое окно могут показываться отдельно. Программы с повышенными правами могут ограничивать переключение или ввод из Бета 1, запущенной без повышения прав.
