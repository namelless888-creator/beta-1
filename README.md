# Бета 1 · 0.2.0

Настраиваемое оформление рабочего стола Windows 10 2004+ и Windows 11 x64. Обои приложение не изменяет.

## Скачать и запустить

Скачайте `Beta1.exe` из **Releases**. Если релиз ещё не опубликован, откройте **Actions → Build Windows → успешный запуск → Artifacts → Beta1-Windows-x64**, распакуйте архив и запустите EXE. Для обновления сначала завершите старую версию через её значок в трее. Установка .NET и права администратора не требуются.

## Изменения в 0.2.0

- Исправлены обрезанные кнопки верхней панели и иконки дока: размеры окон учитывают внутренние отступы.
- Панели привязаны к краям экрана, док центрируется и уменьшается при нехватке места, чтобы не перекрывать собственный трей.
- Иконки и подписи масштабируются; текстовые заменители управляющих значков заменены системным шрифтом Segoe MDL2 Assets.
- Стандартная панель задач скрывается автоматически; учитываются основные и дополнительные панели на других мониторах, повторное появление панели и перезапуск Explorer.
- Ярлыки `.lnk` и `.url` с рабочего стола, импортированные в Бета 1, автоматически убираются с рабочего стола на время работы. Другие файлы, папки, EXE и системные значки остаются на месте.
- Собственный трей справа внизу: фирменный значок Бета 1, сеть, звук, часы и заряд батареи. Нажатие на значок Бета 1 открывает настройки; правый клик — меню, включая выход и возврат панели задач Windows.
- Отдельное окно «Панель управления»: масштаб 70–140%, иконки приложений 24–72 px, иконки дока 24–64 px, плотность фона, подписи, выбор папок, автозапуск и сброс положения.
- Настройки меняются сразу. Открыть их можно из собственного трея, дока, верхней панели или меню «Пуск» → **Бета 1 — Настройки**. Повторный запуск EXE тоже открывает настройки работающего экземпляра.
- Добавлено восстановление рабочего стола при выходе и отдельный процесс восстановления после аварийного завершения.

## Как устроено восстановление

Ярлыки не удаляются: они временно перемещаются в `%LOCALAPPDATA%\Beta1\desktop-links`, а исходные пути записываются в `desktop-recovery.json` **до** перемещения. Приложение запускает их из временного хранилища и сохраняет закрепления с исходными путями. При выходе ярлыки возвращаются. Если по исходному пути появился новый файл, он не перезаписывается: восстановленный ярлык получает дополнительный суффикс.

После аварии отдельный процесс восстановления возвращает ярлыки и панель задач. После отключения питания восстановление выполняется при следующем запуске. Если общая папка рабочего стола требует прав администратора, недоступные ярлыки остаются на месте. Папки OneDrive синхронизируют временное перемещение ярлыков как обычное перемещение файлов.

Отключить скрытие панели задач и перенос дубликатов можно независимо в настройках. При выходе восстанавливаются только панели задач, которые скрывало приложение.

## Управление

- **Alt + перетаскивание** — переместить панель.
- **Правый клик на приложении** — закрепить / убрать из дока.
- **Esc** — скрыть выбранную панель; показать панели снова можно из меню значка Бета 1.
- Музыкальный виджет читает название, исполнителя, обложку и прогресс из системной медиасессии Windows; кнопки отправляют медиаклавиши.

## Сборка и проверки

```powershell
dotnet publish Beta1.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
.\publish\Beta1.exe --integration-test
.\publish\Beta1.exe --smoke-test
```

CI на Windows проверяет избирательный перенос ярлыков, восстановление после имитации аварии, сохранность посторонних файлов и конфликтов имён. Проверка интерфейса открывает семь панелей и окно настроек, перебирает крайние размеры и масштаб, проверяет границы экрана и отсутствие пересечения дока с треем. Проверки не включают скрытие реального рабочего стола runner.

## Ограничения

Собственный трей содержит элементы Бета 1 и системные кнопки; значки уведомлений сторонних приложений из трея Explorer пока не переносятся. Панели размещаются на основном мониторе. Игры фильтруются по имени ярлыка. Приложения без ярлыков меню «Пуск» пока не перечисляются. Панели используют тонированную прозрачность, без настоящего Acrylic-размытия. Поведение с Win+D, полноэкранными играми, пользовательскими темами и нестандартным масштабированием ещё требует проверки на пользовательском Windows.
